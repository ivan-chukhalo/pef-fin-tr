# Технологічний стек

| Частина | Вибір | Чому |
|---|---|---|
| Мова | TypeScript | ловить помилки з сумами і типами даних; типи для таблиць можна згенерувати із Supabase |
| Фронтенд | React + Vite | зрозумілий поділ на компоненти; Vite — швидкий запуск і збірка |
| Стилі | Tailwind CSS | швидке створення інтерфейсу, зручна темна тема, адаптивність префіксами |
| Маршрутизація | React Router | переходи між сторінками без перезавантаження |
| База, вхід, доступ | Supabase (безкоштовний тариф) | PostgreSQL, вхід через email і пароль, Row Level Security |
| Графіки | Recharts | зрозумілі діаграми для React |
| Хостинг | Netlify або Vercel (безкоштовно) | автоматичне оновлення після push у main |
| Репозиторій | GitHub | історія змін, зв'язок з хостингом |
| Редактор | VS Code | вбудований термінал, Git |

## Не використовуємо і чому
- **Next.js** — збірку й маршрутизацію забезпечує поточний стек React + Vite, а дані й автентифікацію обслуговує Supabase.
- **No-code платформи** — менше контролю над кодом і аналітикою.
- **Redux та складні менеджери стану** — для одного користувача вистачає вбудованих механізмів React і запитів до Supabase.
- **Власний бекенд (Node.js, Express)** — дублює функції Supabase без потреби.

## Важливі деталі
- Публічний anon key Supabase можна використовувати в браузері, але тільки разом із правилами Row Level Security.
- Service key Supabase ніколи не потрапляє в код фронтенду і не комітиться.
- Змінні середовища зберігаються у файлі `.env.local`, який додано до `.gitignore`.

## Підключення monobank

Маршрут `/api/monobank` працює як функція Vercel. Під час локальної розробки той самий обробник запускає Vite. Браузер передає токен своєї сесії Supabase, а сервер звіряє ідентифікатор власника й читає виписку з банку.

Для локального підключення задай у `.env.local` `MONOBANK_TOKEN` (персональний токен банку) та `MONOBANK_OWNER_ID` (UUID власника з Supabase Authentication). Ці змінні серверні й мають імена без префікса `VITE_`. [Персональний API monobank](https://api.monobank.ua/)

Для запуску інтеграції на Vercel задай ті самі змінні в налаштуваннях проєкту.
