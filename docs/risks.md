# Технічні ризики і захист

## Високий ризик

**1. Фінансові дані видимі стороннім.**
Неправильні правила Row Level Security дають доступ до даних з публічного ключа.
*Захист:* RLS на кожній таблиці. Після налаштування перевірити доступ з вікна браузера без входу. Дані без входу не мають відкриватись.

**2. Втрата даних.**
Для проєктів на безкоштовному тарифі Supabase рекомендує регулярно експортувати дані. [Документація Supabase](https://supabase.com/docs/guides/platform/backups)
*Захист:* раз на місяць зберігати JSON-копію окремо. Кнопка «Експорт» у застосунку запланована на версію 1.1.

Для ручного експорту відкрий PowerShell у папці проєкту. Потрібен вхід у Supabase CLI 3 та URL проєкту в `.env.local`.

```powershell
.\scripts\export-data.ps1
```

Команда виводить шлях до файлу в `%LOCALAPPDATA%\pef-fin-tr\backups`. JSON містить рахунки, категорії, транзакції, перекази й шаблони повторюваних операцій, разом із прихованими записами. До копії входять також позначки використаних і видалених категорій. Суми в копійках і курси записані текстом, щоб зберегти точність.

**3. Помилки в грошових розрахунках.**
Округлення курсу, переведення в копійки, знак суми при переказі.
*Захист:* суми в копійках, сума в гривнях фіксується при збереженні, тестові сценарії балансу (витрата, дохід, переказ, долар).

## Середній ризик

**4. Пауза безкоштовного проєкту Supabase** після тижня без активності.
*Захист:* користуватись застосунком регулярно, а якщо довго не заходиш — зайти хоча б раз на кілька тижнів.

**5. Код, який не розумієш.**
Вайбкодинг може дати працюючий, але незрозумілий код.
*Захист:* маленькі кроки, коміт після кожної функції, читати згенерований код перед прийняттям.

**6. Вхід на втраченому пристрої.**
Без кнопки «Вийти» сесія залишається активною.
*Захист:* у Supabase можна відкликати сесії або змінити пароль.

**7. Зміна умов безкоштовних тарифів** (Supabase, Netlify, Vercel).
*Захист:* регулярний експорт даних і збереження коду в GitHub.

## Низький ризик

**8. Незручний інтерфейс на телефоні.**
*Захист:* перевіряти кожну сторінку на реальному телефоні.

**9. Курс долара вводиться вручну.**
Можна забути або ввести неправильно.
*Захист:* підставляти останній використаний курс як значення за замовчуванням і показувати його у формі.

**10. Зміна схеми після запуску.**
*Захист:* зміни тільки через міграції, а не вручну в інтерфейсі Supabase.
